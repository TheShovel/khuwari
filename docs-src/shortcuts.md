## Playback {#playback}

| Key | Action |
| --- | --- |
| <kbd>Space</kbd> | play or pause |
| <kbd>Left</kbd> | step one frame back |
| <kbd>Right</kbd> | step one frame forward |

[[fig:keys]]

## Editing {#editing}

| Key | Action |
| --- | --- |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | delete the selected keyframe |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Z</kbd> | undo |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> or <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Y</kbd> | redo |

Shortcuts are ignored while you are typing in a field. They are polite like that.
